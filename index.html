Hướng dẫn sử dụng chi tiết

Tìm hiểu cách sử dụng ứng dụng một cách hiệu quả

Các định dạng được hỗ trợ:

  • Excel (.xlsx, .xls): File Excel tiêu chuẩn của Microsoft
  • CSV (.csv): File dữ liệu phân tách bằng dấu phẩy
  • Chọn nhiều file: Bạn có thể chọn nhiều file nguồn cùng lúc để xử lý hàng loạt

💡 Mẹo: Mỗi file nguồn cần được gán một cấu hình ánh xạ tương ứng. Nếu các file có cấu trúc giống nhau, bạn có thể sử dụng chung một cấu hình ánh xạ.

Cách thực hiện:

  1. Nhấn nút "📂 Tải file nguồn"
  2. Chọn file(s) từ máy tính của bạn (có thể chọn nhiều file bằng Ctrl/Cmd + Click)
  3. Các file sẽ hiển thị trong danh sách "Dữ liệu nguồn" với kích thước và số dòng

Cách gán cấu hình ánh xạ:

  1. Trong danh sách "Dữ liệu nguồn", tìm file bạn vừa tải lên
  2. Nhấn vào dropdown "Chọn cấu hình" bên cạnh file
  3. Chọn cấu hình ánh xạ phù hợp từ danh sách (ví dụ: "Abc_config")
  4. File sẽ được đánh dấu với badge màu xanh khi đã gán cấu hình thành công

⚠️ Lưu ý: Nếu chưa có cấu hình ánh xạ phù hợp, bạn cần tạo mới trong mục "Quản lý ánh xạ" trước khi có thể gán cho file nguồn.

Quản lý thư mục Mapping:

  • Chọn thư mục: Nhấn nút "📂 Chọn thư mục mapping" để tải tất cả cấu hình từ thư mục
  • Tự động nhớ: Ứng dụng sẽ ghi nhớ thư mục mapping và tự động hỏi tải lại khi bạn mở trang
  • Tải lại: Nhấn "🔄 Tải lại" để cập nhật danh sách cấu hình từ thư mục đã chọn

Quy trình chuyển đổi:

  1. Đảm bảo tất cả file nguồn đã được gán cấu hình ánh xạ
  2. Nhấn nút "🔄 Chuyển đổi dữ liệu"
  3. Hệ thống sẽ:
    • Đọc dữ liệu từ các file nguồn
    • Áp dụng cấu hình ánh xạ đã chọn
    • Điền giá trị mặc định (nếu có)
    • Tạo file Excel mới theo template
  4. File kết quả sẽ tự động tải xuống vào thư mục Downloads
  5. Mở file kết quả bằng Excel để kiểm tra và import vào template Excel

✅ Kết quả: File Excel được tạo ra có định dạng chuẩn theo template, đã sẵn sàng để import vào phần mềm khác nhau mà không cần chỉnh sửa thêm.

Tên file kết quả:

Định dạng: converted_YYYY-MM-DD_HH-mm-ss.xlsx

Ví dụ: converted_2025-10-13_14-30-45.xlsx

Bước 1: Tải file nguồn và template

  1. Vào tab "Quản lý ánh xạ"
  2. Nhấn "📂 Tải file nguồn" để chọn file dữ liệu mẫu
  3. Nhấn "📋 Tải template" để chọn file template Excel
  4. Hệ thống sẽ tự động đọc và hiển thị danh sách các cột

Bước 2: Thiết lập ánh xạ cột

  • Cột Template: Danh sách các cột trong file template
  • Ánh xạ tới cột nguồn: Chọn cột tương ứng từ file nguồn
    • Chọn "Không ánh xạ" nếu cột không cần dữ liệu từ nguồn
    • Chọn tên cột nguồn phù hợp để ánh xạ dữ liệu
  • Giá trị mặc định: Nhập giá trị cố định sẽ áp dụng cho tất cả dòng
    • Ví dụ: Cột "Loại tiền" → Giá trị mặc định "VND"
    • Ví dụ: Cột "Tỷ giá" → Giá trị mặc định "1"

📌 Ghi chú: Nếu một cột được ánh xạ từ nguồn và cũng có giá trị mặc định, giá trị mặc định sẽ được ưu tiên sử dụng.

Bước 3: Lưu cấu hình

  1. Nhập tên cho cấu hình (ví dụ: "ABC_config")
  2. Nhấn nút "💾 Lưu cấu hình"
  3. Cấu hình sẽ được lưu vào trình duyệt và có thể tái sử dụng
  4. File JSON cấu hình sẽ tự động tải về thư mục Downloads

Quản lý cấu hình đã lưu:

  • Xem danh sách: Tất cả cấu hình đã lưu hiển thị trong tab "Quản lý ánh xạ"
  • Chỉnh sửa: Nhấn nút "✏️ Sửa" để chỉnh sửa cấu hình hiện có
  • Xóa: Nhấn nút "🗑️ Xóa" để xóa cấu hình không cần dùng
  • Sao chép: Tải file JSON về, đổi tên và tải lại để tạo cấu hình tương tự

Tại sao sử dụng file JSON?

  • Backup cấu hình ánh xạ để tránh mất dữ liệu
  • Chia sẻ cấu hình với đồng nghiệp
  • Chuyển cấu hình giữa các máy tính khác nhau
  • Quản lý nhiều phiên bản cấu hình

Xuất cấu hình ra file JSON:

  1. Khi lưu cấu hình mới, file JSON tự động tải về thư mục Downloads
  2. Hoặc: Vào tab "Quản lý ánh xạ", chọn cấu hình, nhấn "📥 Xuất JSON"
  3. File JSON có tên theo định dạng: [tên_cấu_hình].json
  4. Di chuyển file JSON vào thư mục mapping/ để quản lý tập trung

Nhập cấu hình từ file JSON:

  1. Cách 1: Sử dụng thư mục mapping
    • Nhấn "📂 Chọn thư mục mapping"
    • Chọn thư mục chứa các file JSON cấu hình
    • Tất cả cấu hình sẽ được tải tự động
  2. Cách 2: Tải từng file riêng lẻ
    • Vào tab "Quản lý ánh xạ"
    • Nhấn "📥 Nhập JSON"
    • Chọn file JSON từ máy tính

🎯 Khuyến nghị: Nên tổ chức tất cả file JSON cấu hình trong một thư mục (ví dụ: mapping/) và sử dụng tính năng "Chọn thư mục mapping" để quản lý dễ dàng hơn.

Cấu trúc file JSON: 

{
  "configName": "Abc_config",
  "mapping": {
    "Ngày chứng từ": "Date",
    "Số chứng từ": "Invoice No",
    "Diễn giải": "Description",
    "Loại tiền": "",
    "Tỷ giá": ""
  },
  "defaultValues": {
    "Loại tiền": "VND",
    "Tỷ giá": "1"
  }
}

Tính năng lịch sử:

  • Tự động lưu lại mỗi lần chuyển đổi dữ liệu thành công
  • Hiển thị thông tin chi tiết: thời gian, file nguồn, cấu hình đã dùng, số dòng
  • Badge thông báo số lượng lịch sử mới trên menu
  • Xem lại kết quả các lần chuyển đổi trước đó

Thông tin được lưu:

  • Thời gian: Ngày giờ thực hiện chuyển đổi
  • File nguồn: Danh sách các file nguồn đã xử lý
  • Cấu hình: Cấu hình ánh xạ đã sử dụng cho mỗi file
  • Số dòng: Tổng số dòng dữ liệu đã chuyển đổi
  • Trạng thái: Thành công hoặc có lỗi

Quản lý lịch sử:

  1. Vào tab "Lịch sử" để xem danh sách
  2. Nhấn vào từng mục để xem chi tiết
  3. Nhấn "🗑️ Xóa tất cả" để xóa toàn bộ lịch sử
  4. Lịch sử được lưu trong trình duyệt (LocalStorage)

⚠️ Lưu ý: Dữ liệu lịch sử chỉ lưu trong trình duyệt hiện tại. Nếu xóa cache hoặc dùng trình duyệt khác, lịch sử sẽ không còn.

Phím tắt hữu ích:

Phím tắt Chức năng
Ctrl+Shift+Delete Xóa tất cả dữ liệu (bao gồm thư mục đã lưu)
Ctrl+Click Chọn nhiều file cùng lúc

Mẹo tăng hiệu suất:

  • Xử lý hàng loạt: Chọn nhiều file nguồn cùng lúc để xử lý nhanh hơn
  • Tái sử dụng cấu hình: Lưu cấu hình ánh xạ để không phải thiết lập lại mỗi lần
  • Thư mục mapping: Tổ chức tất cả file JSON trong một thư mục để quản lý dễ dàng
  • Kiểm tra trước: Luôn mở file kết quả bằng Excel để kiểm tra trước khi import vào phần mềm khác
  • Backup cấu hình: Định kỳ sao lưu các file JSON cấu hình ra nơi an toàn

Xử lý lỗi thường gặp:

Lỗi: "Không tìm thấy cấu hình ánh xạ"

→ Kiểm tra xem bạn đã gán cấu hình cho file nguồn chưa

Lỗi: "File không đúng định dạng"

→ Đảm bảo file là Excel (.xlsx, .xls) hoặc CSV (.csv)

Lỗi: "Không đọc được cột nguồn"

→ Kiểm tra file nguồn có tiêu đề cột ở dòng đầu tiên

💡 Mẹo Pro: Sử dụng tính năng "Chọn thư mục mapping" ngay từ đầu để ứng dụng tự động tải lại cấu hình mỗi khi bạn mở trang, giúp tiết kiệm thời gian đáng kể!
